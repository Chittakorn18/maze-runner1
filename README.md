# 🐭 Micromouse Maze Solver (30x30 Simulator)

## 📖 Project Overview
โปรเจกต์จำลองการทำงานของหุ่นยนต์ Micromouse ในการค้นหาเส้นทางเพื่อไปยังเป้าหมาย (ชีส) ในเขาวงกตขนาด 30x30 ช่อง (สเกล 1 ช่อง = 16 เซนติเมตร) ตัวโปรแกรมรองรับการควบคุมทั้งแบบผู้ใช้กดเดินเอง (Manual) และโหมด AI ค้นหาเส้นทางอัตโนมัติ (Auto)

## ✨ Features
* **Procedural Maze Generation:** สร้างเขาวงกตแบบสุ่ม พร้อมระบบล็อก Seed (2026) เพื่อให้ง่ายต่อการประเมินผล
* **Manual Mode:** ควบคุมหุ่นยนต์แบบเรียลไทม์ด้วยปุ่ม `W` `A` `S` `D`
* **Auto Mode (AI Pathfinding):** หุ่นยนต์เดินหาเป้าหมายอัตโนมัติด้วยอัลกอริทึม **Greedy Depth-First Search (DFS)** ควบคู่กับ **Backtracking** 
* **Dynamic Heuristics:** AI มีการดึงค่าระยะห่างจากชีส (Manhattan Distance) มาปรับน้ำหนักทิศทาง (Dynamic Weighting) ทำให้หนูจัดลำดับความสำคัญของเส้นทางและเข้าถึงเป้าหมายได้ไวขึ้น

## 🚀 How to Run (วิธีการรันโปรแกรม)
1. ตรวจสอบให้แน่ใจว่าติดตั้ง **Python 3.x** ในเครื่องเรียบร้อยแล้ว
2. เปิด Terminal หรือ Command Prompt ในโฟลเดอร์ที่เก็บไฟล์โค้ด
3. รันคำสั่งด้านล่างเพื่อเริ่มการจำลอง:
   ```bash
   python micromouse.py
